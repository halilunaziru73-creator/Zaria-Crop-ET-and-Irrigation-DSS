# Security Policy

This repository contains a desktop research/decision-support application and
is not intended to run as a networked service, so the typical web-application
vulnerability surface does not apply.

## Reporting a concern

If you find something in this repository that could pose a security or data-
integrity risk, please open a [GitHub Issue](../../issues) describing it.
Response times are best effort, as this is an independently maintained
research repository.

## Supported versions

Only the latest tagged release is actively maintained.
